1 — Basic Syntax Rules

Comments
Use # to write a comment. Everything after it is ignored by the compiler.
# This is a comment
say -> "Hello"  # inline comment
Case Sensitivity
Keywords are case-insensitive. SAY, Say, say all work. Variable names ARE case-sensitive.
SAY -> "works"
say -> "also works"
Code Blocks
Blocks of code go inside { } curly braces. Indent inside for readability.
check x > 5 {
  say -> "big"
}
Data Types
Four built-in types — no declarations needed. SYLESS figures out the type automatically.
42        # number (integer or decimal)
"Hello"   # string (single or double quotes)
true      # boolean
false     # boolean
null      # null / no value
nothing   # same as null (more readable)
📢

2 — Output

say / show
Print any value
Use say -> to print. The arrow -> is optional. show is a friendlier alias that needs no arrow at all.
say -> "Hello, World!"  # classic style
say "Hello, World!"     # arrow is optional
show "Hello, World!"    # show = no arrow needed
show 42
show myVar
String interpolation NEW
Embed variable names directly inside a string using {variableName}. No more manual concatenation with +.
make name = "Alice"
make score = 95

# Old way:
say -> "Hello, " + name + "! Score: " + score

# New way (much easier!):
say -> "Hello, {name}! Score: {score}"
Print expressions
Math, function calls, and combined values work directly.
show x * 2 + 1
show len(name)
show "Result: {x * 2}"  # expressions in {}
Tip: Use show when you're just learning — it reads the most naturally. Use say -> if you prefer the original style. Both do exactly the same thing.
📦

3 — Variables

make
Declare a variable
Use make name = value to create a variable. Any type of value works.
make x = 10
make name = "Alice"
make flag = true
make nums = [1, 2, 3]
Reassign a variable
After the first declaration, update a variable without make.
make score = 0
score = 100    # update value
score = score + 5 # old way
Compound assignment NEW
Shorthand for updating a variable. += adds, -= subtracts, *= multiplies, /= divides. Much shorter than writing x = x + 5.
make score = 0
score += 10   # score is now 10
score += 5    # score is now 15
score -= 3    # score is now 12
score *= 2    # score is now 24
score /= 4    # score is now 6
⌨️

4 — User Input

ask
Read from user
Use ask variable -> "prompt" to read a line typed by the user and store it.
ask name -> "Enter your name: "
say -> "Hello, " + name

ask age -> "Enter your age: "
say -> age

6 — Conditionals

check / also check / otherwise
If statement
Run a block only when the condition is true.
make age = 18
check age >= 18 {
  show "You can vote"
}
If / else
Add otherwise { } to handle when the condition is false. (else also works.)
check score >= 50 {
  show "Pass"
} otherwise {
  show "Fail"
}
Else-if chain with also check NEW
Chain multiple conditions using also check. Only the first matching branch runs. Great for letter grades, menus, and multi-case logic.
make score = 75

check score >= 90 {
  show "Grade: A"
} also check score >= 80 {
  show "Grade: B"
} also check score >= 70 {
  show "Grade: C"
} otherwise {
  show "Grade: F"
}
Compound conditions
Combine multiple conditions with and / or / not.
check x > 0 and x < 100 {
  show "valid range"
}

check not flag {
  show "flag is false"
}
🔄

7 — Loops

loop / repeat / for each
Repeat N times
Run a block an exact number of times. Both loop and repeat work — pick whichever reads better.
loop 5 times {
  show "Hello!"
}

repeat 5 times {
  show "Hello!"
}
Range loop NEW
Loop from a start number to an end number (inclusive), with a named counter variable you can use inside the block.
# loop i from 1 to 5 → runs with i = 1, 2, 3, 4, 5
loop i from 1 to 5 {
  show "Step {i}"
}

# countdown: loop from 10 to 1
loop n from 1 to 10 {
  show "Number: {n}, Squared: {n * n}"
}
While loop
Keep running while a condition stays true. Now you can use compound assignment to update the counter cleanly.
make count = 0
repeat while count < 5 {
  show "Count: {count}"
  count += 1  # compound assignment
}
For each (iterate)
Loop through every item in an array or collection, one at a time.
make fruits = ["apple", "mango", "banana"]
for each fruit in fruits {
  show "Fruit: {fruit}"
}
⚙️

8 — Functions

task / give
Define a function
Use task name(params) { } to define a reusable block of code.
task greet(name) {
  say -> "Hello, " + name
}

greet("Alice")  # call the function
Return a value
Use give to return a result from a function (like return in other languages).
task add(a, b) {
  give a + b
}

make result = add(3, 7)
say -> result  # prints 10
Recursive function
A function can call itself. Always include a base case to stop the recursion.
task factorial(n) {
  check n <= 1 {
    give 1
  }
  give n * factorial(n - 1)
}
say -> factorial(5)  # 120
Multiple parameters
Functions can take multiple inputs, separated by commas.
task power(base, exp) {
  give base ** exp
}
show power(2, 10)  # 1024
Default parameters NEW
Give a parameter a fallback value. If the caller doesn't pass it, the default is used. Perfect for optional settings.
task greet(name, msg = "Hello") {
  show "{msg}, {name}!"
}

greet("Alice")            # Hello, Alice!
greet("Bob", "Welcome")    # Welcome, Bob!
🔢

9 — Arrays

Create & access
Arrays use square brackets. Elements start at index 0.
make arr = [10, 20, 30, 40]
say -> arr[0]  # 10 (first)
say -> arr[3]  # 40 (fourth)
Add & remove
push adds to the end; pop removes from the end.
make list = [1, 2, 3]
push 4 into list  # [1,2,3,4]
pop from list     # removes 4
Mixed arrays
Arrays can hold any mix of values.
make mixed = [1, "hello", true, 3.14]
say -> mixed[1]  # "hello"

10 — Built-in Functions

length · upper · lower · round · absolute
Syntax
Write function of expression. The result can be used anywhere — inside show, make, a condition, or a string template.
make word = "hello"
show length of word         # 5
show upper of word          # HELLO
show lower of "WORLD"       # world
show round of 3.7           # 4
show absolute of -42        # 42
SYLESSPythonDescription
length of xlen(x)Number of characters or array items
upper of xx.upper()Convert string to UPPERCASE
lower of xx.lower()Convert string to lowercase
round of xround(x)Round number to nearest integer
absolute of xabs(x)Absolute value — removes the negative sign
Used inside strings & conditions
Builtins work anywhere an expression is valid.
make name = "alice"
show "Hello, {upper of name}!"   # Hello, ALICE!

make arr = [1, 2, 3, 4, 5]
check length of arr > 3 {
  show "Array has {length of arr} items"
}

12 — Sorting & Searching

sort / binary search
Sort ascending
Sorts an array in place, smallest to largest.
make nums = [5, 2, 8, 1, 9]
sort nums ascending
say -> nums  # [1, 2, 5, 8, 9]
Sort descending
Sorts an array in place, largest to smallest.
make nums = [5, 2, 8, 1, 9]
sort nums descending
say -> nums  # [9, 8, 5, 2, 1]
Binary search
Finds the index of a value in a sorted array. Returns -1 if not found. Array must be sorted first.
make sorted = [1, 5, 10, 15, 20]
binary search 15 in sorted
# prints: 3 (index of 15)
